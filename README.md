## AI는 어떻게 공부할까?

| 단계 | 하는 일 |
|---|---|
| **직감** (신경망) | 판을 보고 "여기가 좋아 보인다", "누가 이기고 있다"를 한 번에 떠올린다 |
| **탐색** (MCTS) | 후보 수를 수백 번 미리 둬 보며 정말 좋은 수인지 검산한다 |
| **자가대국** | 자기 자신과 둔 판을 기보로 쌓아 다시 공부한다 |

## 🧱 벽, 그리고 🐟 메기

자기 자신과만 두면 **판세 판단(가치망)의 착각이 상대에게도 똑같이 있어서** 고쳐지지 않습니다.
가치망을 아예 꺼 본 모델이 오히려 최고난도 문제 18번을 **0/3 → 3/3**으로 풀어낸 것에서 착안해,
판단력을 일부러 끈 복사본(메기)을 리그에 넣었습니다.

> 미꾸라지만 있는 수조에 메기 한 마리를 넣으면, 미꾸라지들이 긴장해서 더 건강해진다.

**다섯 마리 토끼** (설계상의 성질입니다. 학습 효과와는 별개이며, 효과는 아래 검증에서 나타나지 않았습니다)

- **간단함** · 복사해서 판세를 읽는 눈 하나만 끄면 끝
- **저렴함** · 따로 학습시킬 것이 없다 (추가 비용 0)
- **범용성** · 스스로 배우는 AI라면 어떤 게임에도 쓸 수 있다
- **난도 자율 조절** · 메기는 매번 지금의 모델에서 새로 태어나 함께 자란다
- **순수성** · 사람의 기보도, 다른 엔진의 도움도 쓰지 않는다

## 🧪 검증 결과: 현재 테스트한 규모에서는 효과 없음 (2026. 11.)

메기를 넣은 v3가 강해진 것만으로는 메기 덕분인지 알 수 없어서, **메기만 다르고 나머지는 모두 같은** 통제 실험을 했습니다.

- 같은 코드, 같은 초기 가중치(시드 고정), 차이는 메기 설정 한 줄
- 결과를 보기 전에 예측과 판정 기준을 파일로 기록하고 지문(SHA-256)을 남김 (사전 등록)
- 판정 기준: 시드 1~3 합산 직접 대결에서 메기 쪽 점수의 95% 신뢰구간 하한이 50% 초과

| 실험 | 메기 쪽 점수 (60 에폭 직접 대결) |
|---|---|
| 시드 1 | 58.8% (200판, 96승 43무 61패) |
| 시드 2 | 43.0% (150판) |
| 시드 3 | 44.5% (200판) |
| **합계 550판** | **49.3%** (95% 구간 약 46~53%) → **효과 없음** |

추가로 확인한 것 (사전 등록 판정에는 쓰지 않음):

- 메기를 **더 세게** 하면 오히려 나빠짐 (42.5%)
- 70 에폭 모델에서 분기해 이어 학습해도 차이 없음 (51.5%)
- 정체기 확인 P (11/03): 본 학습 ep543에서 분기해 27 에폭 추가 학습 → ep570 직접 대결 200판 메기 쪽 48.0%, 가치 착각 교정·전술 테스트도 차이 없음. 착취 견고성(맹점) 측정은 공격자 학습이 성립하지 않아 판정 보류
- 재검증 (11/11): 시드 1~3 체크포인트, 이전에 쓰지 않은 새 시작 위치로 추가 대국을 사전 등록(목표 1,350판). 약 460판에서 중단, 합산 메기 쪽 49.3%로 다시 50%와 구별되지 않음 (부분 결과). 메기 비중 50% 학습(K50)도 ep5에서 중단
- 가치망에 일부러 착각을 심어도 **자가대국만으로 1~10 에폭 만에 회복** → 2인 대국에서는 진 쪽 수에 매번 −1이 붙어 착각이 오래 숨지 못함
- 메기 대국이 새 국면으로 데려가는 정도(+4.6%p)는 이미 쓰고 있는 무작위 오프닝보다 훨씬 작음

> **결론: 현재 테스트한 규모(11x11, 128x8 신경망, 60 에폭, 시드 3쌍)에서는 효과 없음.**
> 이 규모에서는 메기가 하려던 일을 자가대국이 이미 혼자 잘하고 있었습니다.
> 더 큰 판, 더 큰 신경망, 더 긴 학습, 더 많은 시드에서는 시험하지 않았습니다. 이 결과를 끝으로 메기 연구를 종료했습니다(2026-11-11).
> 자세한 내용: [`docs/CATFISH_report.md`](docs/CATFISH_report.md) 9~10장

## 🤝 AI 도구를 어떻게 썼는가

이 프로젝트는 **AI 코딩 도구(Anthropic의 Claude, Claude Code)와 함께** 만들었습니다. 무엇을 누가 했는지 사실대로 적습니다.

**AI 도구가 한 일**
- 코드 작성과 수정(학습 루프, C++ 탐색 엔진, 대국·평가 스크립트, 웹 데모 포팅 등)
- 실험 실행 보조: 스크립트 실행, 로그 확인, 결과 집계, 표와 그래프 작성
- 문서 초안(사전 등록 문서, 기록 정리)과 결과 해석에 대한 토론 상대

**사람(저자)이 한 일**
- 무엇을 검증할지 정하는 일: 메기 학습법 아이디어, 11x11로의 복귀, 대조군을 처음부터 다시 학습하는 설계 선택
- 판정 기준과 시드·판 수를 결과를 보기 전에 정하고, 그대로 지킨 것
- 결과가 기대와 달라도 "효과 없음"으로 닫고, 사후에 만든 변형은 탐색 결과로 구분한 것
- 어떤 실험을 언제 멈출지 결정한 것 (이 저장소의 중단 결정은 모두 저자의 지시)
- 환경(한 대의 노트북 GPU)과 비용 제약 아래서 우선순위를 정하는 일

**한계**
- AI 도구가 작성한 코드는 모든 줄을 저자가 직접 검토하지는 않았습니다. 중요한 수치는 로그와 재측정으로 확인했지만, 코드 오류의 가능성은 남아 있습니다.
- 결과 해석과 문장 표현에는 AI 도구의 도움이 들어 있습니다.
