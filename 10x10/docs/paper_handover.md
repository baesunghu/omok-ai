# 논문 작업 인수인계 (2026-10-12)

새 세션(Sonnet)에서 논문 작업을 이어 가기 위한 문서. 메모리 파일(MEMORY.md)은 자동으로 불러오므로 여기서는 **논문에 관한 맥락만** 정리한다.

## 0. 가장 중요한 원칙

- **사용자가 직접 읽고 직접 쓴다.** ("순수하게 다 하고 싶다", 2026-10-12)
  - 서론·본문 문장을 대신 써 주지 않는다. 뼈대, 질문, 배치, 표현 피드백, 사실 확인만 돕는다.
  - 참고 논문도 사용자가 직접 전부 읽는다. 요약·완역을 대신 만들지 않는다 (완역은 저작권상 불가).
  - 사용자가 막힌 문장/개념을 물으면 설명한다.
- **내용 먼저, 형식은 나중.** 하고 싶은 말을 먼저 정하고(브레인스토밍) 그다음 논문 형식에 배치한다.
- 답변은 한국어, 중립적 어조. 사실과 다른 숫자를 지어내지 않는다 — 수치는 아래 "근거 문서"에서 확인.

## 1. 현재 단계: 브레인스토밍

오늘 목표(사용자): 논문의 개괄적인 틀, 특히 서론의 방향 잡기.

진행 방식 (사용자 동의함):
1. 하고 싶은 말을 판단 없이 한 줄씩 20~30개 적는다 (사용자가 작성 중).
2. 비슷한 것끼리 3~5 덩어리로 묶는다.
3. "이 논문이 남기고 싶은 단 하나"를 고른다 → 제목·서론의 중심.
4. 덩어리를 서론/방법/결과/논의에 배치하고, 빈칸을 찾는다.

떠올리기 질문: 친구에게 3분 자랑한다면? 가장 놀랐던 순간? 가장 힘든 실패? 다른 사람이 가져갔으면 하는 교훈? 아직 못 푼 문제?

사용자가 목록을 붙이면 2~3단계 정리를 돕는다 (내용은 사용자 문장 그대로, 배치만).

## 2. 정해진 것

**제목 (사용자 확정)**
- 정오(NOON): 패배에 음수 가중치를 준 게이팅을 이용한 11×11 오목 AI
- NOON: An 11×11 Gomoku AI with Negative Weight on Losses at Gating
- NOON = Neural Omok On a Notebook (여명 → 정오)

**저자 표기 (사용자 결정 진행 중)**
- 표지안: 대구고등학교 시카모어 / 배성훈 인더스트리 연구(팀) / 배 성 훈
- 외부 공개 논문이면: 배성훈 (Sunghun Bae), 소속은 독립 연구자 또는 대구고등학교(시카모어). "배성훈 인더스트리"는 등록 단체가 아니면 소속 칸보다 프로젝트명/감사의 글이 안전하다고 조언함.

**중심 연구 질문 (사용자, 2026-09-30)**
- "자원이 부족한 환경(노트북 한 대)에서 평범한 사람을 이기는 AI를 만들 수 있는가"
- 동기: 2026년은 알파고-이세돌 대국 10주년.

**구성 요소의 출처 정리 (사용자 확인)**
- 자가대국 학습: AlphaZero
- 게이팅: AlphaGo Zero (기준 55% 승률). AlphaZero는 게이팅을 없앰.
- 패배 음수 가중치: 이 연구. 점수 = (승 + 0.5×무 − 0.75×패) / 판수, 50% 초과 시 승격 (2026-10-11 도입).
- **사다리 승격 (두 번째 변주, 2026-10-12 도입)**: 게이트는 best와의 상성에 휘둘림(905가 약 95에포크 동안 best, 960은 Rapfi 기준 더 강한데도 게이트 탈락). Rapfi 사다리로 잰 대등국면이 best보다 높고 부트스트랩으로 "더 셀 확률" ≥ 80%면 승격 (`ladder_promo.py`). ep960이 이 경로로 승격(P 87%, 4,432 vs 2,907). 사용자 비유: 게이트 = 수시, 사다리 = 정시. 효과는 이후 학습 결과로 확인 필요. 논문에서는 "최초" 단정 대신 "제안한다/우리가 아는 한 드물다"로.

**목차 초안 (확정 아님, 브레인스토밍 후 조정)**
1. 서론 2. 관련 연구 3. 방법 (자가대국 구조 / 패배 음수 가중치 게이팅 / Rapfi 사다리와 검증) 4. 실험 환경 5. **개발 경과(모델 계보)** — 사용자가 꼭 넣고 싶어 함, 본문에 큰 전환점 4~5개, 세부는 부록 6. 결과 7. 논의와 한계 8. 결론 9. 부록

**서론 문단별 질문 (사용자가 직접 씀)**
배경(자가대국 RL의 성과) → 문제(대규모 자원 전제) → 연구 질문 → 작은 환경의 어려움(불안정한 학습, 실력 측정 기준 부재) → 접근과 기여 → 논문 구성. 숫자는 기여 문단에 모은다.
