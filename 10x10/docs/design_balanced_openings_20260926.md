# 설계안: 균형 시작 국면 도입 (방안 3)

작성: 2026-09-26 · 상태: **설계 단계 (미배포)**

## 1. 배경

- 11x11 자유 오목은 선공이 거의 다 이긴다. 라운드로빈에서 선공(X)이 72판 중 68판을 이겼다.
- 그래서 자가대국의 후공 쪽 학습 신호가 대부분 "결국 짐(-1)"이다. 막는 수가 좋았는지 구분할 신호가 거의 남지 않는다.
- 게이트도 사실상 "누가 더 잘 뚫나"로 판정돼서 공격형 모델이 승격된다. epoch 345에서 승격된 뒤 더블포 방어가 50%에서 20%로 떨어졌다.
- 측정 결과 (epoch 354):

| | 공격 | 방어 |
|---|---|---|
| 4목 (1수) | 90% | 95% |
| 열린 3 (2~3수) | 100% | 74% (평균) |
| 더블포 | 100% | 20% |
| T자 삼삼 | 실패 | 실패 |

## 2. 목표

**"공격형을 방어형으로 바꾸기"가 아니라 "공격형에 방어를 얹기".**
공격 점수는 유지하고 방어 점수만 올린다. 정답 수를 주입하지 않고, 게임 조건만 공정하게 만든다. 연구 원칙(자가대국으로 스스로 학습)을 지키기 위해서다.

## 3. 설계

### 3.1 시작 국면 세트 만들기
1. 현재 best 모델로 빈 판에서 짧은 오프닝을 둔다. 4~8수, 온도를 높게 하거나 무작위 수를 섞어 다양성을 확보한다.
2. 각 국면을 가치망과 MCTS(400 sims 정도)로 평가한다.
3. 가치가 **-0.3에서 +0.3 사이**인 국면만 남긴다.
4. 대칭(8방향)으로 겹치는 국면을 제거하고, **300~500개**를 모은다.
5. `model/balanced_openings_11x11.pkl`에 저장한다. 주기적으로(예: 50에폭마다) 새 모델로 재평가해서 갱신한다.

### 3.2 자가대국에 섞기
- 판의 **50%는 균형 국면**에서 시작하고 **50%는 빈 판**에서 시작한다. 빈 판 대국이 공격 감각을 유지한다.
- 균형 국면에서 시작한 판도 시작 국면 이후의 수만 학습 샘플로 쓴다. 생존 라벨(남은 수)도 시작 이후 기준으로 계산한다.
- 비율은 설정값으로 둔다. 공격 점수가 떨어지면 균형 국면 비율을 낮춘다.

### 3.3 게이트에 적용
- 게이트 20판 중 일부 또는 전부를 균형 국면에서 시작한다. 같은 국면을 두 모델이 흑백을 바꿔 한 번씩 둔다(국면당 2판).
- 선공이 자동으로 이기지 않으므로 방어력이 결과에 반영된다.
- 보조 조건으로 방어 단계 검사 점수가 best보다 크게 떨어지지 않을 것을 추가한다(방안 1).

### 3.4 공격형 기준 모델 보존
- 현재 best(공격형)와 `v2_final_best_ep284.pth`를 얼려서 리그 상대로 유지한다.
- 새 모델이 날카로운 공격을 막아내는 경험을 계속 하게 하고, 공격력이 떨어지는지 확인하는 기준으로도 쓴다.

## 4. 평가

- `fork_status_check.py`의 공격·방어 단계 검사를 10에폭마다 실행한다.
- 성공 기준: **방어(열린 3, 더블포)는 상승하고, 공격(4목, 열린 3, 더블포)은 유지**된다.
- 저장된 체크포인트들로 추세를 측정하고, 단발 측정으로는 판단하지 않는다.

## 5. 위험과 대응

| 위험 | 대응 |
|---|---|
| 공격 감각이 무뎌짐 | 빈 판 비율 유지, 공격 점수 감시, 비율 조정 |
| 시작 국면 분포가 실전과 다름 | 빈 판 50% 유지 |
| 국면 세트가 낡음(모델이 강해지면 균형이 깨짐) | 주기적 재평가·갱신 |
| 구현 버그로 학습 붕괴 | 배포 전 백업, 별도 파일로 작업 후 교체 (기존 관례) |

## 6. 엔터테인먼트 관점 (축제 사용)

현재 모델은 **"공격은 날카로운데 방어가 덤벙대는"** 성격이다. 관람객 입장에서는 이 약점이 오히려 인간다움과 재미를 준다. 이기려면 AI의 방어 허점을 찾아야 하는, 도전할 만한 상대가 되기 때문이다.
그래서 방어를 올리더라도 **축제용으로 현재 공격형 모델을 별도로 보존**하는 것을 권장한다. 난이도 단계(예: 공격형 = 보통, 방어 보강형 = 어려움)로 활용할 수 있다.
