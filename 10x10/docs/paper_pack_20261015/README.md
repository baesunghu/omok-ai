# 논문 초본 재료 (2026-10-15 저녁 정리)

목적: 오늘 밤(21시~) 워드로 논문 전체 초본을 쓰기 위한 재료. **문장은 직접 쓴다.** 여기에는 목차, 각 칸에서 답할 질문, 넣을 그림, 확인된 수치(출처 포함)만 있다.

쓰는 순서 권장: 방법 → 결과 → 개발 경과 → 논의·한계 → 서론 → 결론 → 초록. 서론을 먼저 쓰면 막힌다.

## 1. 목차와 칸마다 답할 질문

**제목** (확정): 정오(NOON): 패배에 음수 가중치를 준 게이팅을 이용한 11×11 오목 AI
/ NOON: An 11×11 Gomoku AI with Negative Weight on Losses at Gating (NOON = Neural Omok On a Notebook)

**초록** (마지막에, 4~6문장): 무엇을 / 어떤 환경에서 / 어떻게 / 무엇이 나왔나(숫자 2~3개) / 의미.

### 1. 서론
- 배경: 자가대국 강화학습(AlphaGo → AlphaGo Zero → AlphaZero)은 무엇을 해냈나? 2026년이 알파고-이세돌 10주년이라는 점.
- 문제: 그 성과들은 어떤 규모의 자원을 전제로 했나?
- 연구 질문: "노트북 한 대로 평범한 사람을 이기는 AI를 만들 수 있는가"
- 작은 환경의 어려움 두 가지: 학습이 불안정하다 / 실력을 잴 기준이 없다(손실 ≠ 실력).
- 접근과 기여: 이 논문이 내놓는 것 2~3개 (패배 음수 가중치 게이팅, Rapfi 사다리 측정·승격, 노트북에서의 개발 기록). 숫자는 이 문단에 모은다.
- 논문 구성 한 문장.

### 2. 관련 연구
- AlphaGo / AlphaGo Zero / AlphaZero 각각 한두 문장: 무엇이 달랐나 (특히 게이팅: AGZ는 55% 기준, AZ는 없앰).
- KataGo: 적은 자원으로 효율을 높인 기법(Playout Cap Randomization → 본 연구의 PCR).
- 오목: Allis 1994(흑 필승 증명), Rapfi(강한 오픈소스 엔진, 측정 기준으로 사용, GPL-3.0).
- 이 연구의 자리는 어디인가? (대규모 X, 단일 노트북 O, 측정 방법 제안)

### 3. 방법
3.1 전체 구조 — 그림 1개짜리 문단으로 충분: 자가대국 → 버퍼 → 학습 → 게이트 → best 갱신. 신경망 구조, MCTS 시뮬레이션 수.
3.2 패배 음수 가중치 게이팅 — 식: 점수 = (승 + 0.5×무 − 0.75×패) / 판수. 왜 패배를 더 무겁게 봤나? 기준값의 변천(아래 표).
3.3 Rapfi 사다리 — 여러 노드 단계(예: 300~10,000)와 각각 n판 → 단계별 승률을 로짓으로 바꿔 직선 맞춤 → 50%가 되는 노드 = "대등국면". 부트스트랩으로 68/95% 범위. 검증 결과(920, 51.2%).
3.4 사다리 승격 — 게이트(best와의 상성)만으로는 놓치는 경우가 있어 추가. "게이트 = 수시, 사다리 = 정시" 비유를 쓸지?
3.5 실력 평가 — 졸업 문제(측정 전용, 학습에 넣지 않음), 사람과의 웹 대국.

### 4. 실험 환경
- 하드웨어, 판 크기, 신경망 크기, 주요 설정값 (아래 표 B).
- 지도학습 출발점(Gen12)을 쓴 이유.

### 5. 개발 경과 (모델 계보)
- 본문엔 큰 전환점 4~5개만 표로 (아래 표 C). 세부 세대표는 부록 → `10x10/docs/NAPS_lineage.md`.
- 각 전환점: 무엇이 문제였고, 무엇을 바꿨고, 결과는?

### 6. 결과
6.1 대등국면 성장 — 그림 1. 여명 959 → ep960 4,432(25개 시작 국면 재측정 3,454).
6.2 직접 대결 — 그림 2.
6.3 사람과의 대국 — 웹 82판 결과.
6.4 사례: 스냅스루 (3,7) — 엔진이 두지 않는, 더 버티기 쉬운 수를 스스로 찾음. 이후 960은 정석으로 돌아감.
6.5 사례: 가치망 제거 실험 — 유전병 = 가치망 과신 + 정책망 맹점.

### 7. 논의와 한계
- 손실과 실력이 따로 움직인 사례(그림 3, 15×15 그림 5).
- 측정 오차: 단계당 20~40판이라 범위가 넓다.
- 웹 대국은 소수 테스터, 대부분 약한 수준.
- 15×15 확장: 진행 중, 아직 지도학습 출발점(ep0)을 넘지 못함 → 정직하게 "진행 중"으로 (그림 4·5).
- 시간 제한 채점의 비결정성 → 노드 제한으로 바꾼 교훈.

### 8. 결론
- 연구 질문에 대한 답 한 문단. 남은 일.
